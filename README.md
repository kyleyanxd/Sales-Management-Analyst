# Sales-Management-Analyst

## Data Source & Database Setup

The analysis in this project uses the **AdventureWorksDW2019** data warehouse database from Microsoft. 

Because the raw `.bak` file exceeds file size limits, it is not hosted directly in this repository. 

* **Database File:** `AdventureWorksDW2019.bak`
* **Download Link:** You can download the official backup file directly from https://learn.microsoft.com/en-us/sql/samples/adventureworks-install-configure?view=sql-server-ver15&tabs=ssms 
* **Restoration:** Once downloaded, restore the `.bak` file in SQL Server Management Studio (SSMS) to run the queries provided in the `Sql Queries` folder.
